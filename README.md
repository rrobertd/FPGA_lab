# FPGA_lab

### This repository was made to keep projects made while I was preparing for the Digital Logic Laboratory.

In this repository I keep my Verilog projects. 

With no familiarity of Verilog or Vivado, I started by implementing basic gates to test out the Design Suite tools and to familiarize myself with Verilog.

Currently I'm implementing the combinational logic elements (Adders and flip-flops).
